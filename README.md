# URL-shortener

**URL-shortener** — это проект на языке C#, реализующий сервис для сокращения URL-адресов.

---

## Описание

Проект представляет собой веб-приложение для создания коротких ссылок из длинных URL. Это упрощает их распространение и использование. В проекте используются следующие технологии:

- C# (.NET) — основная технология разработки
- ASP.NET Core — веб-фреймворк
- PostgreSQL — база данных
- Entity Framework Core — ORM для взаимодействия с базой данных
- Docker — для контейнеризации и развёртывания приложения

---

## Возможности

- Создание коротких URL из длинных ссылок
- Перенаправление по короткой ссылке на исходный URL

---

## Структура проекта

- `src/UrlShortener` — исходный код приложения
- `docker-compose.yaml` — конфигурация для запуска приложения и связанных сервисов в Docker
- `.gitignore` — настройки игнорирования файлов Git
- `.dockerignore` — настройки игнорирования файлов в Docker-контексте
- `UrlShortener.sln` — решение Visual Studio

---

## Требования и установка

- Установленный .NET SDK версии 9 или новее (для локального запуска)
- Docker (для запуска в контейнерах)

### Локальный запуск

1. Клонируйте репозиторий:

```
git clone https://github.com/roge66/first-project.git
cd first-project
```

2. Запустите проект из IDE или с помощью CLI:

```
dotnet run --project src/UrlShortener/UrlShortener.csproj
```

### Запуск через Docker

1. Выполните команду:

```
docker-compose up -d
```

2. Приложение будет доступно по адресу `http://localhost:80`

---

## Использование

Для создания короткой ссылки отправьте запрос на API endpoint `HTTP POST /shorten`.

Ответом будет короткая ссылка, которую можно использовать для быстрого перехода через API endpoint `HTTP GET /{shortCode}`.
